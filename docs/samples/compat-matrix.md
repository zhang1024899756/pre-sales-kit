## 产线能耗与设备监控平台 v3.2 · 兼容性矩阵

华东区 · 智能制造事业部 ｜ 更新日期：2025-11-20

### 操作系统

| 环境 | 支持情况 | 说明 |
| --- | --- | --- |
| Windows Server 2012 R2 | 部分支持 | 仅支持 v3.0 以前版本的采集驱动，需关闭 TLS 1.3 |
| Windows Server 2016 | 部分支持 | 需补丁 KB4532945 |
| Windows Server 2019 | 完全支持 | — |
| Windows Server 2022 | 完全支持 | — |
| CentOS 7.9 | 部分支持 | 需 glibc 2.28 以上；官方已停止维护 |
| Ubuntu 22.04 LTS | 完全支持 | — |
| 麒麟 V10 SP3 | 待确认 | 有客户在用，尚未完成完整回归 |

### 数据库

| 环境 | 支持情况 | 说明 |
| --- | --- | --- |
| Oracle 19c | 完全支持 | — |
| Oracle 12c | 部分支持 | 需 12.2.0.3 以上补丁 |
| Oracle 11g | 不支持 | 建议升级至 19c |
| MySQL 8.0 | 完全支持 | — |
| MySQL 5.7 | 部分支持 | 2023 年 10 月已 EOL，仅存量项目维护 |
| PostgreSQL 15 | 完全支持 | — |
| 达梦 DM8 | 部分支持 | 需开启 Oracle 兼容模式 |

### 浏览器

| 环境 | 支持情况 | 说明 |
| --- | --- | --- |
| Chrome 100+ | 完全支持 | — |
| Edge 100+ | 完全支持 | — |
| 360 安全浏览器（极速模式） | 部分支持 | 必须切到极速内核，兼容模式不支持 |

### 已验证的组合

| 操作系统 | 数据库 | 结论 | 说明 |
| --- | --- | --- | --- |
| Windows Server 2016 | Oracle 11g | 不支持 | 补丁依赖与 Oracle 11g 客户端冲突 |
| Windows Server 2019 | Oracle 19c | 完全支持 | 已通过 48 小时压测 |
| CentOS 7.9 | 达梦 DM8 | 部分支持 | 需额外安装达梦客户端驱动 |

> 本矩阵覆盖 v3.2 的现场部署形态；组合未列出的，按各维度中最差的一项判断。
